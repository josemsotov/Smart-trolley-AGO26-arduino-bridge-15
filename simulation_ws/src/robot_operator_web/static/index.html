Control manual y seguridad

Funciones del mando Stadia

El movimiento deliberado de la palanca izquierda cancela FOLLOWER y recupera el control manual. Al conectar, el perfil desplegado toma control con una orden STOP inicial y aplica las zonas muertas configuradas.

Los botones no mostrados como activos no tienen función asignada. El botón STOP rojo de la interfaz permanece disponible en todo momento.

Marcas manuales sobre el tiempo del archivo.

El paso por fotogramas es aproximado para videos de tasa variable. Un video exportado en camara lenta ya tiene el tiempo dilatado: no representa automaticamente la duracion real del swing. La revision de videos del telefono es manual; no calcula velocidad de bola ni del palo.

Revisión de swing a alta velocidad

La cámara global shutter de 90 FPS permite revisar las fases del swing con menor distorsión de movimiento.

  • Maestro 1080p/90 FPS para conservar evidencia
  • Proxy 540p/90 FPS para revisión fotograma a fotograma
  • Velocidad de bola y distancia aún requieren radar o launch monitor
